Document-to-risk LLM workflow

In production
AI cybersecurity startup (US), platform for CISOs · via Sirius Software

Customers upload their own security documents (policies, pen tests, board decks) and the platform proposes risks and initiatives for their security program, instead of someone entering them by hand.

  • Workflow on Temporal with retries and idempotent writes; an LLM step synthesizes candidates.
  • Matching before proposing: a tiered matcher compares each candidate with existing rows and an LLM adjudicator decides whether it updates a row or is new, so a second document doesn't create duplicates.
  • Human in the loop: proposals land in a review UI where the team accepts or rejects each one.
  • Evals in CI with labeled examples, so a prompt or model change that makes results worse fails before it ships.

Construction-management platform

In production
Arquinering, construction and real-estate company in Buenos Aires · freelance, team of three

An internal platform that replaced spreadsheets for running construction projects: budgets, cost control, progress billing, purchasing, labor and planning. The site and finance teams use it every day.

  • Started from the process: I sat down with the site and finance teams to map how they budget, buy and bill before writing code.

  • Separate dev and production environments, end-to-end tests with Playwright.

Voice copilot for Claude Code

Personal project · prototype
iPhone app + local server

Talk to Claude Code from my phone, hands-free: an iPhone app sends voice to a small server on my Mac, which drives Claude Code headless with my own subscription and reads the answer back.

  • MCP callback: the server exposes an MCP endpoint that the headless agent calls back into.
  • Finds and resumes existing Claude Code sessions; read-only by default.
  • Speech-to-text with whisper.cpp, long-polling for tasks that take longer than a request allows.
